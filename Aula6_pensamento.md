11. O que define a característica de 'Finitude' em um algoritmo?
 
Resposta: É a propriedade que garante que o algoritmo deve terminar em algum momento, ou seja, ele possui um número limitado e definido de passos — não pode ficar rodando infinitamente.
 
 
 
12. No modelo IPO (Entrada–Processamento–Saída), o que representa a Entrada?
 
Resposta: São as informações, dados ou valores que o programa recebe do usuário ou de outra fonte antes de começar a trabalhar.
 
 
 
13. Analogia: No preparo de um bolo, o que seria o 'Input' (Entrada)?
 
Resposta: Seriam os ingredientes (farinha, açúcar, ovos, leite, etc.) — tudo o que você usa para fazer o bolo.
 
 
 
14. O que ocorre na etapa de Processamento de um programa?
 
Resposta: É quando o programa realiza os cálculos, transformações, comparações e operações lógicas com os dados que recebeu na entrada, para chegar ao resultado.
 
 
 
15. Analogia: No preparo de um bolo, o que representa o Processamento?
 
Resposta: Seria misturar os ingredientes, bater, assar no forno — ou seja, tudo o que você faz com os ingredientes para transformá-los em bolo.
 
 
 
16. O que é a Saída (Output) em um algoritmo?
 
Resposta: É o resultado final que o programa entrega após processar as informações — a resposta ou o valor gerado.
 
 
 
17. Analogia: Como a Saída de um programa se assemelha a servir um bolo?
 
Resposta: Assim como a saída é o resultado pronto entregue ao usuário, servir o bolo é entregar o produto final pronto para consumo.
 
 
 
18. O que é uma Variável na programação?
 
Resposta: É um espaço reservado na memória do computador, com um nome, onde guardamos um valor que pode ser alterado e usado durante o programa.
 
 
 
19. Analogia: Qual objeto doméstico representa bem uma variável?
 
Resposta: Uma caixa ou pote com etiqueta — a etiqueta é o nome da variável, e o que está dentro é o valor guardado; dá pra trocar o conteúdo quando quiser.
 
 
 
20. Como o Python identifica o tipo de uma variável?
 
Resposta: O Python descobre sozinho pelo valor que você coloca nela — não precisa dizer qual é o tipo. Se colocar número, ele entende número; se colocar texto, ele entende texto.
21 — O que o tipo de dado 'int' (inteiro) armazena?
👉 Armazena números inteiros, sem vírgula/ponto decimal. Exemplos: 5, 0, -10, 999.
 
22 — Para que serve o tipo de dado 'float'?
👉 Serve para números com casas decimais (números reais). Exemplos: 3.14, 10.5, -2.75.
 
23 — O que representa o tipo de dado 'str' (string)?
👉 Representa textos, palavras, frases ou sequências de caracteres, sempre entre aspas. Exemplo:  "Cleidimar" ,  "Vila Velha" .
 
24 — O que armazena uma variável do tipo 'bool' (booleano)?
👉 Armazena apenas dois valores:  True  (verdadeiro / sim) ou  False  (falso / não).
 
25 — Analogia: Como o tipo 'bool' pode ser usado para verificar o forno?
👉 Pode indicar se o forno está ligado = True ou desligado = False; ou se está quente = True / frio = False. É uma pergunta que só tem sim ou não como resposta.
 
26 — O que é uma Constante em programação?
👉 É um valor que não muda ao longo do programa. É definido uma vez e fica igual o tempo todo — não pode ser alterado depois.
 
27 — Qual a convenção visual para nomear constantes em Python?
👉 Escrever tudo com letras MAIÚSCULAS, separando palavras por underline. Exemplo:  PI = 3.1415 ,  VELOCIDADE_MAXIMA = 100 .
 
28 — Qual o símbolo utilizado para 'Atribuição' em Python?
👉 É o sinal de igual:  = . Exemplo:  idade = 30  → guarda o número 30 dentro de idade.
