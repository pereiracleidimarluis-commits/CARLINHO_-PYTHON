11. O que define a característica de 'Finitude' em um algoritmo?
 
Resposta: É a propriedade que garante que o algoritmo deve terminar em algum momento, ou seja, ele possui um número limitado e definido de passos — não pode ficar rodando infinitamente.
 
 
 
12. No modelo IPO (Entrada–Processamento–Saída), o que representa a Entrada?
 
Resposta: São as informações, dados ou valores que o programa recebe do usuário ou de outra fonte antes de começar a trabalhar.
 
 
 
13. Analogia: No preparo de um bolo, o que seria o 'Input' (Entrada)?
 
Resposta: Seriam os ingredientes (farinha, açúcar, ovos, leite, etc.) — tudo o que você usa para fazer o bolo.
 
 
 
14. O que ocorre na etapa de Processamento de um programa?
 
Resposta: É quando o programa realiza os cálculos, transformações, comparações e operações lógicas com os dados que recebeu na entrada, para chegar ao resultado.
 
 
 
15. Analogia: No preparo de um bolo, o que representa o Processamento?
 
Resposta: Seria misturar os ingredientes, bater, assar no forno — ou seja, tudo o que você faz com os ingredientes para transformá-los em bolo.
 
 
 
16. O que é a Saída (Output) em um algoritmo?
 
Resposta: É o resultado final que o programa entrega após processar as informações — a resposta ou o valor gerado.
 
 
 
17. Analogia: Como a Saída de um programa se assemelha a servir um bolo?
 
Resposta: Assim como a saída é o resultado pronto entregue ao usuário, servir o bolo é entregar o produto final pronto para consumo.
 
 
 
18. O que é uma Variável na programação?
 
Resposta: É um espaço reservado na memória do computador, com um nome, onde guardamos um valor que pode ser alterado e usado durante o programa.
 
 
 
19. Analogia: Qual objeto doméstico representa bem uma variável?
 
Resposta: Uma caixa ou pote com etiqueta — a etiqueta é o nome da variável, e o que está dentro é o valor guardado; dá pra trocar o conteúdo quando quiser.
 
 
 
20. Como o Python identifica o tipo de uma variável?
 
Resposta: O Python descobre sozinho pelo valor que você coloca nela — não precisa dizer qual é o tipo. Se colocar número, ele entende número; se colocar texto, ele entende texto.
21 — O que o tipo de dado 'int' (inteiro) armazena?
👉 Armazena números inteiros, sem vírgula/ponto decimal. Exemplos: 5, 0, -10, 999.
 
22 — Para que serve o tipo de dado 'float'?
👉 Serve para números com casas decimais (números reais). Exemplos: 3.14, 10.5, -2.75.
 
23 — O que representa o tipo de dado 'str' (string)?
👉 Representa textos, palavras, frases ou sequências de caracteres, sempre entre aspas. Exemplo:  "Cleidimar" ,  "Vila Velha" .
 
24 — O que armazena uma variável do tipo 'bool' (booleano)?
👉 Armazena apenas dois valores:  True  (verdadeiro / sim) ou  False  (falso / não).
 
25 — Analogia: Como o tipo 'bool' pode ser usado para verificar o forno?
👉 Pode indicar se o forno está ligado = True ou desligado = False; ou se está quente = True / frio = False. É uma pergunta que só tem sim ou não como resposta.
 
26 — O que é uma Constante em programação?
👉 É um valor que não muda ao longo do programa. É definido uma vez e fica igual o tempo todo — não pode ser alterado depois.
 
27 — Qual a convenção visual para nomear constantes em Python?
👉 Escrever tudo com letras MAIÚSCULAS, separando palavras por underline. Exemplo:  PI = 3.1415 ,  VELOCIDADE_MAXIMA = 100 .

👉 É o sinal de igual:  = . Exemplo:  idade = 30  → guarda o número 30 dentro de idade.

31 — Qual a função do operador de resto da divisão (%)?
 
👉 Calcula o resto que sobra quando se divide um número por outro. Exemplo:  7 % 3 = 1  (sobra 1).
 
32 — Para que servem os Operadores Relacionais?
 
👉 Comparam dois valores entre si (maior, menor, igual, diferente...) e devolvem Verdadeiro ou Falso.
 
33 — Qual a diferença entre = e == em Python?
 
👉  =  é atribuir (guarda valor na variável) |  ==  é comparar se são iguais (responde Sim/Não).
 
34 — O que o operador != verifica?
 
👉 Verifica se os valores são DIFERENTES um do outro.
 
35 — Como funciona o operador lógico 'and'?
 
👉 Os dois lados PRECISAM ser verdadeiros ao mesmo tempo. Se um for falso, tudo dá falso.
 
36 — Em que situação o operador 'or' retorna verdadeiro?
 
👉 Basta UM dos lados ser verdadeiro que já dá certo. Só dá falso se os dois forem falsos.
 
37 — O que faz o operador lógico 'not'?
 
👉 Inverte o resultado: o que era verdadeiro vira falso, e o que era falso vira verdadeiro.
 
38 — Para que serve a estrutura condicional 'if'?
 
👉 Verifica uma condição: se for verdadeira, executa o que está abaixo dela.
 
39 — Qual a função do 'else' em uma estrutura condicional?
 
👉 É o "senão": se o  if  não for verdadeiro, ele executa o que está no  else .

📝 41 — O que é a Indentação em Python e por que é obrigatória?
 
É o espaço/recuo no começo da linha, que organiza o código em blocos. Em Python não usa chaves {}, então a indentação é obrigatória — é ela que diz qual código pertence a qual bloco. Se errar, o programa não funciona.

📝 43 — Qual a finalidade da função input()?
 
Serve para receber o que o usuário digita pelo teclado. O programa para e espera a pessoa digitar, então guarda aquela informação.

Porque o input SEMPRE entrega como texto (letra/palavra), mesmo que o usuário digite número. E não dá pra fazer conta com texto → precisa transformar em número primeiro.

📝 52 — Qual a função da instrução len() aplicada a uma lista?
 
Conta quantos itens tem dentro da lista. Se tem 5 coisas → mostra 5. É o "tamanho" da lista.
 
📝 53 — Como o método pop() remove elementos de uma lista?
 
Remove o ÚLTIMO item da lista, por padrão. Se colocar um número entre parênteses → remove daquela posição. Exemplo:  lista.pop(2)  tira o item da posição 2.
 
📝 54 — Para que serve o método sort() em listas?
 
Organiza em ORDEM CRESCENTE. Números do menor ao maior; textos em ordem alfabética.
 
📝 55 — Qual a utilidade do operador 'in' com listas?
 
Verifica se um item EXISTE dentro da lista. Devolve  True  (tem) ou  False  (não tem). Exemplo:  "banana" in frutas  → diz se tem banana na lista.
 
📝 56 — O que é um Teste de Mesa (ou Dry Run)?
 
É simular o código com a mão, passo a passo, sem rodar no computador. A gente anota os valores e vê se dá certo → serve para achar erros antes de rodar.
 
📝 57 — Analogia: Como o Teste de Mesa se aplica ao seguir uma receita?
 
É ler a receita ANTES de cozinhar, imaginando cada passo: medir os ingredientes na ordem, conferir quantidades, ver se não esqueceu nada. Igual seguir o código linha por linha.
 
📝 58 — Qual o objetivo de usar uma Tabela de Acompanhamento no teste de mesa?
 
Anotar numa tabelinha o valor de cada variável em cada passo. Assim não se perde e enxerga direitinho quando cada número muda.
 
📝 59 — O que é um Erro de Sintaxe?
 
É erro de escrita/gramática do código: esqueceu dois-pontos, parêntese fechando errado, palavra mal escrita. O programa nem chega a rodar → já avisa logo no começo.
 
📝 60 — O que caracteriza um Erro de Execução?
 
A sintaxe está escrita certa, mas o programa encontra um problema NO MEIO do caminho e para de repente. Exemplo: tentou dividir por zero, procurar posição que não existe, valor com tipo errado. Ele começa a rodar e dá erro depois.

📝 62 — Qual a diferença entre Interpretadores e Compiladores?
 
Interpretador: lê e executa linha por linha, na hora. Não gera arquivo separado. → Python é assim.
Compilador: traduz TODO o código de uma vez antes de rodar, cria um arquivo executável. Depois roda esse arquivo. Mais rápido depois de pronto.
