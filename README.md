ALGORITIMO PYTHON

1.Compreender o problema
É entender exatamente o que precisa ser
resovido:quais são os dados de entrada,
regras e resultado se espera e quais são as
regras e restricões do problema.É a base de tudo-
sem entender bem o pra problema,não dá pra resolver!
2.DECOMPOR O PROBLEMA 
É dividir o problema grande em partes 
menores emais simples,ficando mais fácil
de resolver cada pedacinho separadamente
e depois juntar tudo.É como cortar uma  tarefa grande em peqenas 
tarefas.
3.INDETIFCAR PADRÕAES
É procurar semelhanças,repetições ou características que que se repetem no problema.quando encontramos padrões,podemos criar soluções que servem para vários casos,não só para um.
4.ABSTRAIR INFORMÇÕES
É focar só no que é importante e ignorar detalhes que não ajudam na solucão.tiramos o que é desnecessário e mantemos apenas os dados e regras que realmente importam para resolver o problema.
5.CRIAR ALGORITIMO
É montar o passo a passo,a sequencia lógica de instruções que,se seguida corretamente,leva á solução do problema. É o "receituario" da solção,antes de escrever o código.
